# World overhaul

Visual thesis: a warm, sunlit goblin cooking adventure grounded in busy town courtyards, with cream ceramic, timber, worn paving, leafy gardens and believable authored props.

Content plan: the playable kitchen dominates the view; neighboring buildings, streets and seating establish the place; the recipe is one compact note; the contextual action stays close to the bottom edge. Six venues change the surrounding world as the 36-level campaign advances.

Interaction thesis: the rigged chef walks and carries the actual dish; processing tools react during jobs; customers celebrate a successful catch. Reduced motion removes decorative motion while preserving state changes.

The generated target in visual-targets/world-overhaul-target.png is a design reference. Actual browser captures are required for delivery. Collision and recipe state remain independent of decorative model geometry.
